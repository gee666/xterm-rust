# Search verification

Run `node scripts/check-search.mjs` from the repository root with Node 24.15 or newer, Rust 1.85 and the original dependency tree installed under `source_repo/node_modules`. Add the local Cargo bin directory to PATH if the shell does not expose it.

Use an owned O: worktree and private Cargo target with jobs2. Agree the current compiler/browser allocation through the active coordinator; the retired global build-slot queue must not be restored. The checker runs unchanged original SearchEngine and SearchLineCache tests over the original Terminal, verifies retained fixtures, runs its declared Rust targets and warning-denying scoped Clippy, and checks owned Rust formatting. Commands have bounded timeouts. Raw logs, full core dependency snapshots, actual discovered/executed/pass/fail/unrun counts and tool versions go to `results/search/` and per-attempt archives. Changed input snapshots invalidate a run; a compile/resource failure is not a test pass.

`node scripts/search-oracle.mjs` checks the retained corpus rather than overwriting expected results. Only use `node scripts/search-oracle.mjs --generate` when deliberately updating source fixtures, then inspect every fixture and report change. Seed `0x5ea2c001` drives 2048 actual-cell randomized engine cases plus 1024 state cases. The full retained corpus has 2200 engine calls and 6116 wrapped translations including calls observed while the 86 unchanged original assertions run. Original code is bundled into `tmp/search-oracle`; source_repo files are not edited.

Use `search::with_buffer` for real terminal rings, not bounded row snapshots. It preserves stale and signed aliases. RangeError recursion outcomes and distinct nontermination safety guards are checked in `tests/search_ring.rs`. Read `docs/search.md`, `docs/search-addon.md` and `docs/acceptance-search.md`. The cache has explicit host clock and invalidation inputs. Its tests are not proof that terminal event subscriptions or browser timers are connected. The callable SearchAddon uses real terminal selection and decoration services. Run `cargo test --locked -j2 -p xterm-web --test search_addon` and `WASM_TEST=wasm_search_addon node scripts/browser-host-check.mjs` for addon integration. `node scripts/search-call-args-source.mjs` bundles unchanged source classes and replays the same81-case argument fixture used by the Rust WASM suite. Set SOURCE_DEPENDENCIES to an existing reference checkout to reuse Node dependencies without a junction. Read `docs/search-browser-verification.md` and `docs/search-call-args.md` for exact scope, optional-argument declaration checks and raw term/accessor gaps347. The unchanged original browser suite runs through `node scripts/e2e-upstream.mjs --suite addon-search --timeout-ms 180000`; it requires the reference dependency tree and matching wasm-bindgen0.2.100. Always unlink an owned dependency junction before whole-worktree cleanup. Full-family322 and serialization346 remain open beyond these scoped checks. Native Windows execution is not Linux/macOS runtime evidence. Full equivalence is NOT PROVEN.
