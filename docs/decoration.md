# Decoration service and logical-line cache

`crates/xterm-core/src/decoration.rs`, `decoration_service.rs` and `decoration_cache.rs` port the common DecorationService, Decoration and DecorationLineCache classes. `docs/decoration-acceptance.md` lists the full branch contract. OSC link registration is separate in `osc_link_service`.

## Integration

Construct `DecorationService::with_buffers(&BufferSet)` to attach to the active buffer and follow normal/alternate activation. The service owns a weak activation subscription and releases it on disposal or native owner drop. `new()` plus `attach_to_buffer_lines` supports explicit hosts and focused tests.

Registration takes `Rc<RefCell<DecorationOptions>>`. Options remain shared and mutable. A disposed marker returns `Ok(None)`. `Decoration::clone` preserves object identity. The service uses the shared deferred SortedList for source ordering and snapshots. Cell iterators defer bucket lookup until first next, retain the service while active and stay exhausted after completion. They retain a live bucket so removing a visited entry shifts later entries exactly as JavaScript array traversal does. `decorations_on_line` returns a read-only shared bucket handle whose length/content reflect later mutations. Marker disposal removes a decoration from its original indexed line before the public removal event. No RefCell borrow crosses a user callback.

Logical lines retain the authoritative `MarkerLine` Number or UTF-16 String. Cache keys use its SameValueZero Map key, while the shared SortedList reads its raw value for strict and relational comparisons. A string-started span first indexes the String key, then post-increment converts subsequent lines to Number. Height addition preserves string concatenation. Trim converts keys numerically and merges NaN keys without discarding them; insert preserves concatenation and delete uses numeric subtraction. Native heights remain unsigned integers; x and width preserve floating-point comparisons. Arbitrary browser geometry is not established by these integer-height tests. Opaque host element handles use `Rc<dyn Any>`, keeping browser DOM types out of the core. A renderer sets the element with `set_element`, then fires `fire_render` when the upstream render contract calls for it. Lazy foreground/background colors reuse the shared CSS parser and accept a browser canvas fallback. Their cached Rc/RefCell handles preserve IColor identity and external mutation across calls. Parse failures propagate and do not populate the cache.

Insert/delete line events enqueue cache work. Subscribe to `line_cache().on_sync_requested()` and schedule `flush_pending()` through the browser's real queueMicrotask. Do not flush synchronously inside the line event because buffer marker listeners may not have updated yet. Native hosts flush explicitly at the corresponding microtask boundary. Flush returns a Result so non-advancing Number spans are not successful no-ops. Clear cancels queued work; a stale host callback finds no pending actions. Browser renderer/microtask assembly belongs to task32 and remains separately required.
